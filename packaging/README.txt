Cascade: a custom desktop for Windows 11
https://github.com/ayan-pathak/cascade

INSTALL
  1. Extract this zip anywhere.
  2. Double-click Install.cmd. If Windows asks whether to run it, choose Run.
  Cascade installs for your account only (no admin rights), starts now and every time you sign in.

UNINSTALL
  Double-click Uninstall.cmd. The Windows taskbar and your previous wallpaper come back.

GOOD TO KNOW
  - Cascade hides the Windows taskbar and uses its own top bar and dock. Ctrl+Alt+T shows the taskbar again.
  - Ctrl+Alt+P opens Personalize (wallpaper, colours, effects). Ctrl+Alt+K opens search.
  - If Cascade ever crashes and the taskbar stays hidden, run:
      %LOCALAPPDATA%\Cascade\Cascade.exe --restore
  - Needs Windows 11 (or Windows 10 with the Microsoft Edge WebView2 Runtime).
  - The download isn't code-signed yet, so Windows SmartScreen may warn the first time.
    Choose "More info", then "Run anyway".
